# TOGOSHOL — комплект MD-документов для разработки

Проект: минималистичный премиальный лендинг для продажи игровых ПК в Великом Новгороде.

Цель: сделать frontend-часть сайта, который продаёт 5–20 игровых ПК без перегруза каталогом, блогом и лишними секциями.

## Что внутри

```text
00_README.md
01_PROJECT_BRIEF.md
02_DESIGN_SYSTEM.md
03_PAGE_STRUCTURE.md
04_COMPONENTS.md
05_ANIMATIONS.md
06_CONTENT.md
07_CODEX_TASKS.md
08_QA_CHECKLIST.md
```

## Основная идея

TOGOSHOL — локальный премиальный бренд игровых ПК в Великом Новгороде.

Сайт должен выглядеть не как обычный компьютерный магазин, а как чистый high-tech landing в стилистике 2026 года:

- тёмный premium tech;
- cyan / blue / violet glow;
- крупная типографика;
- минимальное количество текста;
- 3 карточки готовых сборок;
- индивидуальный подбор;
- понятная заявка;
- рабочие анимации;
- адаптив под desktop / tablet / mobile.

## Рекомендуемый стек

Если проект уже существует — использовать текущий стек.

Если проект пустой:

- React;
- TypeScript;
- Vite;
- CSS Modules или обычный CSS;
- Framer Motion опционально;
- без backend;
- без реальной корзины;
- без оплаты;
- без лишних страниц.

## Главный принцип

Не перегружать.

Сайт должен продавать ощущение надёжной локальной сборки игровых ПК, а не имитировать большой интернет-магазин.
